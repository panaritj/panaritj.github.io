# Panarit's Engineering Blog

A minimalist technical blog focused on software engineering, generative AI, and clarity of thought. Built for speed, readability, and a distraction-free writing experience. 

## Tech Stack

*   **Framework:** [Hugo](https://gohugo.io/) (Extended)
*   **Theme:** [PaperMod](https://github.com/adityatelange/hugo-PaperMod) (Light mode default)
*   **Hosting & Deployment:** GitHub Pages via GitHub Actions

## Local Development

If you want to clone this repository and run the site locally:

1. **Clone the repository and its submodules** (required to pull the PaperMod theme):

   git clone --recurse-submodules [https://github.com/panarit/panarit.github.io.git](https://github.com/panarit/panarit.github.io.git)
